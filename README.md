# Whispering Village

A low-poly exploration game being developed using Unity and Blender.

## About the Project

Whispering Village is a stylized low-poly game project where players explore different zones of a magical village and uncover hidden elements through exploration.

## Technologies Used

- Unity
- Blender
- C#
- Git & GitHub

## Current Progress

- Village center created
- Houses modeled
- Trees modeled
- Fence assets created
- Environment design in progress

## What I Learned

- 3D modeling in Blender
- Unity scene management
- Asset importing workflow
- Game development fundamentals
- Version control using Git

## Upcoming Features

- Interactive gameplay
- Multiple village zones
- Collectible system
- Sound effects
- UI improvements
